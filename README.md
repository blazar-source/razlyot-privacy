# Политика конфиденциальности — «Разлёт стрелок»

Публичная HTML-политика Android-игры «Разлёт стрелок» (Blazar Games), редакция от 19 октября 2026 года.

- Исходная страница: [index.html](./index.html)
- Планируемый публичный адрес GitHub Pages: https://blazar-source.github.io/razlyot-privacy/
- Планируемый идентификатор приложения в RuStore: `ru.blazarauthor.razlyot`
- Контакт по вопросам данных: blazargames@ya.ru

Страница описывает локальные игровые сохранения, рекламные форматы Яндекс РСЯ и игровую аналитику myTracker, порядок выбора согласия, обращения и удаления данных.

Чтобы ссылка GitHub Pages работала, в настройках репозитория **Settings → Pages** необходимо включить публикацию из ветки `main`, каталог `/ (root)`. После включения Pages проверить сайт в режиме инкогнито и использовать именно работающий адрес в RuStore и приложении.

Не подменять этот документ политикой другой игры. При изменении SDK, идентификатора релизного приложения или порядка обработки данных обновить политику.
